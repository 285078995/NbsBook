# NbsBook —— NBS 乐谱书与孤独的音乐家

适用于 Paper 1.21.11（Java 21）。可以把 NBS 乐谱的指定音轨转成文字写入「书与笔」，再像 NoteBot 一样从书本反推乐谱并演奏；同时会在世界中生成「孤独的音乐家」，为附近的玩家演奏并赠送乐谱书与奖励。

## 功能

1. **导入（/nbs import、/nbs load）**：读取 `.nbs` 文件并转换为书本；`import` 只读取 `nbs/`，`load` 可同时搜索 `nbs/` 和 `musician_songs/`；可配置在乐谱内容前预留空白页。
2. **演奏（/nbs play）**：手持乐谱书执行命令，插件解析书中文字还原乐谱，逐刻播放音符盒声音并显示音符粒子。
3. **停止（/nbs stop）**：只停止由 `/nbs play` 发起的播放。
4. **孤独的音乐家**：敌对怪物生成时有低概率被替换为孤独的音乐家。它使用随机怪物模型，但不攻击玩家；玩家靠近后会开始演奏，演奏结束后可交付乐谱书并给出试炼宝库奖励。
5. **音乐家召唤**：管理员可以用 `/nbs summon` 在当前位置手动生成指定模型和乐谱的音乐家。
6. **唱片机播放**：手持写有乐谱的书与笔右键唱片机，可把乐谱书放入唱片机并从该位置播放；再次右键停止并弹出乐谱书。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/nbs import <文件名> [轨道名称]` | 从 `plugins/NbsBook/nbs/` 导入 `.nbs` 文件并生成乐谱书。省略轨道名称则导入全部轨道；指定轨道名称则只导入该轨道 |
| `/nbs load <文件名> [轨道名称]` | 同时从 `plugins/NbsBook/nbs/` 和 `plugins/NbsBook/musician_songs/` 查找并导入乐谱 |
| `/nbs list` | 显示 `nbs` 目录路径及其中的现有文件，用于核对文件名 |
| `/nbs summon [模型] [乐谱]` | 在当前位置召唤孤独的音乐家。模型省略时随机选择；乐谱省略时从 `musician_songs` 目录随机选择 |
| `/nbs musician <on\|off\|status\|stop>` | 开启、关闭、查看音乐家自动生成，或停止当前音乐家演奏 |
| `/nbs jukebox stop` | 停止由唱片机发起的播放 |
| `/nbs play` | 手持书与笔播放其中乐谱 |
| `/nbs stop` | 只停止由 `/nbs play` 发起的播放 |

## 权限

| 权限 | 默认 | 可用的命令 |
| --- | --- | --- |
| `nbsbook.use` | OP | `/nbs import` |
| `nbsbook.admin` | OP | `/nbs load`、`/nbs list`、`/nbs summon`、`/nbs musician`、`/nbs jukebox` |
| `nbsbook.play` | 所有人 | `/nbs play`、`/nbs stop` |

## 唱片机播放

手持已生成乐谱的书与笔，右键任意唱片机方块，插件会把该乐谱书放入唱片机并从唱片机位置播放乐谱，和放入普通唱片一样。

- 需要 `nbsbook.play` 权限；
- 开始播放时会消耗手中的一本乐谱书，并将其放入唱片机；
- 音源在唱片机方块中心上方，音符粒子也会从该位置出现；
- 再次右键同一个唱片机即可停止播放并弹出乐谱书，和真唱片的使用方式一致；
- 也可以使用 `/nbs jukebox stop`（需要 `nbsbook.admin`）停止声音，乐谱书仍留在唱片机中，之后右键可弹出；
- 插件会持续监听唱片机内容，只要乐谱书离开唱片机（被弹出、取走或由漏斗等移出），就会自动停止播放；
- 如果手中的书本不是有效乐谱，不会干预唱片机的原版交互。

## 目录

- NBS 乐谱文件：`plugins/NbsBook/nbs/`
- 音乐家携带的乐谱文件：`plugins/NbsBook/musician_songs/`

插件首次启动会自动创建这两个目录。放入文件后无需重启服务器，执行对应命令时会重新读取目录。

`/nbs import` 只查找 `nbs/` 目录；`/nbs load` 会依次查找 `nbs/` 和 `musician_songs/`，两个目录存在同名文件时优先使用 `nbs/` 中的文件。

## 孤独的音乐家行为

- 敌对怪物自然生成时，有约 2% 的概率被替换为孤独的音乐家；
- 音乐家会随机采用一种怪物模型，但对玩家无仇恨，且亡灵类模型不会在阳光下燃烧；
- 名称显示为淡灰色，体型保持正常大小；
- 有手的模型会手持一本「乐谱」，无手模型会把乐谱戴在头上；
- 128 格范围内同时最多存在一个孤独的音乐家；
- 玩家进入约 36 格范围后，音乐家开始演奏，音源为音乐家自身，不再向聊天栏发送开始/结束提示；
- 演奏期间音乐家获得无敌效果，演奏结束后恢复；
- 演奏时周围敌对生物会清除对该玩家的仇恨，并给予玩家生命恢复；
- 演奏结束后，玩家在约 5 格内与音乐家对视时，音乐家会丢出乐谱书并给予一份试炼宝库奖励；
- 玩家离开约 128 格后，音乐家会消失；
- 音乐家已交付过的乐谱不会再次被其他音乐家自动携带，直到 `musician_songs` 目录中的所有乐谱都交付过一次后，状态才会重置并开始新一轮。

## 配置

`config.yml` 用于配置音乐家功能和乐谱书生成行为：

```yaml
musician:
  enabled: true
book:
  blank_pages_before: 0
```

也可以在游戏内使用 `/nbs musician on|off|status` 切换，切换结果会保存到配置；使用 `/nbs musician stop` 停止音乐家演奏。

- `musician.enabled`：音乐家自动生成功能是否默认开启；
- `book.blank_pages_before`：生成的乐谱书在乐谱内容前预留多少个空白页，设置为 `0` 表示不预留。该配置对 `/nbs import` 生成的乐谱书和音乐家交付的乐谱书都生效。

## 书本文本格式

```
#NBSBOOK|1|tempo=10.00|name=曲名|author=作者|ticks=总刻数
tick:i0,k45,p2;i4,k45,p2
tick:i0,k47,p2
```

- 每行 `tick:` 表示一个刻（时间点），同一行的音符同时发声（和弦）；
- `i` = 乐器编号（0-15，对应钢琴、贝斯、鼓等 16 种音符盒音色）；
- `k` = 音高（0-87，NBS 定义，33-57 为音符盒两个八度范围）；
- `p` = 距上一个有音符的刻的间隔（tick，起点为 -1）；
- `v` = 音量（0-100，默认省略即 100）。

## 安装

1. 使用 JDK 21 + Maven 构建：

   ```powershell
   mvn clean package
   ```

2. 把 `target/NbsBook-1.0.0.jar` 放入 Paper 服务器的 `plugins/` 目录并重启；
3. 把需要导入的 `.nbs` 文件放入 `plugins/NbsBook/nbs/`；
4. 把音乐家可以携带的 `.nbs` 文件放入 `plugins/NbsBook/musician_songs/`。

## 导入找不到文件时的排查

1. **先在游戏里执行 `/nbs list`**：会显示插件实际读取的目录路径和其中所有文件。如果列表为空，说明文件没放对地方；如果有文件但名字和你输入的不一样，照着列表里的名字导入即可。
2. **确认目录层级**：文件要放在 `plugins/NbsBook/nbs/` 里面，不是 `plugins/NbsBook/`，更不是 `plugins/`。
3. **Windows 隐藏扩展名**：资源管理器默认隐藏已知扩展名，`song.nbs` 可能实际是 `song.nbs.nbs` 或 `song.nbs.txt`。查看方法：资源管理器「查看」→ 勾选「文件扩展名」，确认真实名字后重新命名或按真实名字导入。
4. **Linux 服务器区分大小写**：文件名大小写必须一致，插件已支持忽略大小写匹配。
5. **放文件后无需重启服务器**：导入命令每次执行都会重新读取目录，放好文件后直接执行 `/nbs import` 或 `/nbs load` 即可。

## 技术说明

- 支持 NBS 经典格式及 OpenNBS v1–v5；
- 导入时解析 NBS 轨道名称，`/nbs import` 和 `/nbs load` 的轨道参数按名称匹配且忽略大小写；
- v4 起新增的 velocity/panning/微调音高中仅读取音量，声像与微调音高被忽略（音符盒播放接口不支持这两项）；
- 书与笔游戏内上限为 100 页、每页 1024 字符，超出容量的乐谱导入时会明确报错；
- 播放时音高自动折叠进音符盒可播放的两个八度（33-57），超出部分按八度平移；
- 自定义乐器（编号 > 15）在播放时回退为钢琴音色。
